# Challenge-UI-Gmail-Equipe5

Reproduction de l'interface utilisateur de Gmail en Flutter.

## Démarrage

Ce projet est une application Flutter basée sur un design inspiré de Gmail.

### Prérequis

- Flutter SDK installé
- un émulateur ou un appareil connecté

### Lancer l'application

```bash
flutter pub get
flutter run
```
